# User Roles

## Guest
Can access public information and authentication pages:
- Home
- About
- Events
- Notices
- FAQ
- Contact
- Login
- Register

## Student
Can access student-specific portal pages:
- Dashboard
- Profile
- Courses
- Attendance
- Notices
- Feedback
- Settings
- Logout

## Admin
Will eventually manage:
- Students
- Events
- Dashboard/statistics

At P1, admin functionality is only planned. No permissions or authentication implemented.
