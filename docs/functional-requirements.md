# Functional Requirements

FR-01 Users can access the StudentHub home page.
FR-02 Visitors can view public information.
FR-03 Visitors can view events.
FR-04 Visitors can view notices.
FR-05 Visitors can search/view FAQs.
FR-06 Visitors can access the contact page.
FR-07 Students can access the login page.
FR-08 New students can access the registration page.
FR-09 Students can access a dashboard after authentication.
FR-10 Students can view profile information.
FR-11 Students can view courses.
FR-12 Students can view attendance.
FR-13 Students can submit feedback.
FR-14 Students can manage relevant settings.
FR-15 Admins will eventually manage students and events.
