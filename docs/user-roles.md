# User Roles

## Guest
Can access public information and authentication pages:
- Home
- About
- Events
- Notices
- FAQ
- Contact
- Login
- Register

## Student
Can access student-specific portal pages:
- Dashboard
- Profile
- Courses
- Attendance
- Notices
- Feedback
- Settings
- Logout

## Admin
Manages:
- Students
- Events
- Dashboard/statistics
