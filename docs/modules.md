# Modules

## Core Modules

1. **Public Information** - Home, About, Events, Notices, FAQ, Contact
2. **Authentication** - Login, Register
3. **Student Dashboard** - Dashboard, Profile, Courses, Attendance, Feedback, Settings
4. **Academic Information** - Courses, Attendance
5. **Events** - Event listing, details
6. **Notices** - Important notices, academic notices, general notices
7. **Feedback** - Feedback form, submissions
8. **Administration** - Admin dashboard, student management, event management

No additional modules unless required.
